# Malaysia Population Analysis Dashboard (Tableau)

## Overview

This repository showcases a **group data visualization project** developed using **Tableau**. The project analyzes Malaysia's population trends using public datasets to explore demographic changes across states from **1970 to 2025**.

The dashboard enables users to explore population growth, geographic distribution, and ethnicity composition through interactive visualizations.

---

## My Contribution

This was a **group project**.

My primary contribution was designing and developing the **Population by State Dashboard** using Tableau.

The overall project included:

- Data exploration
- Data preparation
- Dashboard planning
- Interactive dashboard development *(Population Dashboard – My Contribution)*
- Data interpretation and presentation

---

## Dataset

The project uses a Malaysian public dataset from **data.gov.my**.

**Dataset Used**

- Population by State (1970–2025)

---

## Dashboard Features

The dashboard contains three interactive visualizations.

### 1. Population by State

A filled map showing population distribution across Malaysian states.

Provides:

- Geographic population comparison
- State selection
- Interactive tooltips
- Dynamic filtering

---

### 2. Population Growth Over Time

A multi-line chart visualizing long-term population growth trends.

Shows:

- Population trends from 1970–2025
- Comparison between states
- Long-term demographic changes

---

### 3. Population by Ethnicity

A stacked bar chart illustrating the ethnic composition of each Malaysian state.

Allows users to:

- Compare ethnic distributions
- Identify demographic patterns
- Analyze population composition

---

## Interactive Features

- State Filter
- Year Filter
- Sex Filter
- Age Group Filter
- Ethnicity Filter
- Hover Tooltips

---

## Key Insights

- Selangor recorded the highest population growth throughout the study period.
- Population generally increased across all Malaysian states between 1970 and 2025.
- Urbanized states experienced faster population growth than rural regions.
- Ethnic composition differs significantly across Malaysian states, particularly between Peninsular Malaysia and East Malaysia.
